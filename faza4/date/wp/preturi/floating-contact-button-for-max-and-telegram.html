Support the plugin Floating Contact Button for MAX and Telegram (Eng)

Language: 🇷🇺 / 🇬🇧

Hi! My name is Alexander, and I’m the author of the plugin Floating Contact Button for MAX and Telegram.

This plugin adds a simple and elegant floating contact button to WordPress, with support for popular messengers like Telegram, Facebook Messenger and WhatsApp, as well as MAX — a Russian messenger.

You can download the latest version of the plugin from the official WordPress.org repository, or find it directly in your WordPress admin panel via Plugins → Add New.

In the bottom-right corner of this website, you can see the contact buttons in action — this is a live demo of the plugin.

We’ve recently released an updated version with improved UX and design.
The main button now opens enabled messengers with a single click, making contact faster and cleaner.

A PRO version is now available for users who need extended customization options and additional buttons.
The plugin will continue to evolve with a strong focus on simplicity, performance, and clean UI.
