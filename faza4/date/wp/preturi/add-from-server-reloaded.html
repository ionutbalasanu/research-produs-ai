SFTP, or S3-Compatible Storage

Connect a remote server or S3-compatible bucket and browse its folders directly inside WordPress. Stage the files locally and import them seamlessly into your Media Library without any manual downloads, supporting full FTP, SFTP (requires PHP ssh2 extension), and S3 endpoints.

    Frequently Asked Questions

    How does Add From Server work?

    Upload your files to a folder that WordPress can access, then open Add From Server  to browse and select them. Choose the files or folders you want and import them directly into your Media Library.

    Do I need to change my WordPress or PHP upload settings?

    No. The plugin imports files that are already available on your server instead of using the normal browser upload process. This means you do not need to change your WordPress upload settings just to import those files.

    Can I import large videos, images, PDFs, and other files?

    Yes. You can import WordPress supported media files that are already available on your server, including large videos, images, PDFs, audio files, and documents. Unsafe file types such as PHP and executable files are blocked by default but can be enabled by settings.

    Can I import an entire folder?

    Yes. You can select a folder and import the files inside it, including files in its subfolders. This is useful when you have a large collection of files to add at once.

    How does the plugin handle duplicate files?

    The plugin checks for existing files during import. Pro gives you more control, allowing you to skip existing files, replace them, or keep both copies.

    Can Pro import files from FTP, SFTP, or S3?

    Yes. Pro supports FTP, SFTP, and S3 compatible storage, allowing you to browse remote files and import them directly into your WordPress Media Library.

    Can I schedule imports automatically?

    Yes. Pro lets you schedule recurring imports so files can be added to your Media Library automatically without starting each import manually.

    Can I leave the page while a large import is running?

    Yes. Pro supports background imports, so large jobs can continue processing after you leave the import page.
